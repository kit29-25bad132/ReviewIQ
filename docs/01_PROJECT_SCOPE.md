# ReviewIQ — Project Scope

## Project Identity
- **Name:** ReviewIQ
- **Type:** AI-powered product review analyzer
- **Core statement:** Extract pros, cons, star rating, supporting evidence, and summary from raw customer reviews.
- **Positioning:** An LLM-powered structured information extraction system.

## Objective
Demonstrate the complete AI application lifecycle: input, prompting, structured output, validation, persistence, API delivery, UI presentation, testing, and evaluation.

## V1 Features
1. Review input
2. Rating extraction
3. Rating-source classification
4. Pros and cons extraction
5. Evidence extraction
6. Summary generation
7. Structured JSON output
8. Pydantic validation
9. Persistence
10. History
11. Product dashboard
12. Rating distribution
13. Top pros and cons
14. Input validation
15. AI/API/database error handling
16. Automated tests

## Out of Scope
RAG, agents, multi-agent systems, fine-tuning as a V1 dependency, custom ML models, PyTorch, TensorFlow, LangChain, LlamaIndex, multiple LLM providers, Kafka, Redis, microservices, vector databases, web scraping, real-time pipelines, recommendation engines, and advanced semantic clustering.

## Definition of Done
V1 is complete only when the complete lifecycle works, tests pass, deployment succeeds, secrets are protected, documentation is current, and all team members can explain the system.
