# ReviewIQ — Technology Stack

| Technology | Purpose | Selection rationale | Alternatives |
|---|---|---|---|
| Next.js | Frontend framework | React-based application structure and deployment support | Vite/React |
| React | UI components/state | Component model and ecosystem | Other UI frameworks |
| TypeScript | Frontend typing | Safer API and UI contracts | JavaScript |
| Tailwind CSS | Styling | Consistent utility-based styling | CSS modules |
| shadcn/ui | UI primitives | Accessible, composable components | Custom components |
| Lucide | Icons | Consistent icon set | Other icon libraries |
| Recharts | Charts | React-friendly deterministic visualizations | Other chart libraries |
| Python | Backend/AI integration | Readability and AI ecosystem | Node.js |
| FastAPI | REST API | Typed, testable, async-friendly API framework | Next.js API routes |
| Pydantic | Validation/contracts | Runtime schema validation | Manual validation |
| Uvicorn | ASGI server | Runs FastAPI | Other ASGI servers |
| Gemini + Google GenAI SDK | AI analysis | Selected LLM provider for V1 | Other providers |
| Supabase/PostgreSQL | Persistence/analytics | Managed relational database | Other PostgreSQL hosting |
| Pytest | Backend tests | Python testing ecosystem | unittest |
| Vitest | Frontend/unit tests | Fast TypeScript testing | Jest |
| Playwright | E2E tests | Browser-level workflow verification | Cypress |
| Vercel | Frontend deployment | Next.js hosting | Other cloud hosts |
| Render | Backend deployment | Simple Python service deployment | Other platforms |

Versions must be pinned in the implementation repository and updated in this document when changed.
